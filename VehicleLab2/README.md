# Лабораторная работа 2: Автопарк

Проект для Java 11+. Классы `Vehicle`, `Car`, `Motorcycle`, `Truck` и `Main` находятся в отдельных файлах.

## Запуск

Из папки проекта:

```text
javac -encoding UTF-8 src/Vehicle.java src/Car.java src/Motorcycle.java src/Truck.java src/Main.java
java -cp src Main
```

`Vehicle[]` хранит объекты разных классов. Вызов `move()` у каждого элемента выполняет реализацию его фактического класса. Перед приведением к дочернему классу программа проверяет объект через `instanceof`.

Если привести объект `Motorcycle` к `Car` без такой проверки, программа получит `ClassCastException`. Пример неверного приведения не выполняется, чтобы приложение работало без ошибки.

Метод `printInfo()` объявлен как `final`: классы-наследники не могут переопределить его. Внутренний класс `Engine` хранит данные двигателя каждого транспортного средства. Анонимный класс в `Main` задаёт отдельное поведение для прототипа.
